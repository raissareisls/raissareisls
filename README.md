## 🚀 Projetos em Destaque

### **[CodeGirls](https://github.com/raissareisls/CodeGirls.git)** · [Live Demo](https://raissareisls.github.io/CodeGirls/)

Aplicativo voltado à inclusão de mulheres na tecnologia, construído em **Swift** com **SwiftUI** e componentes nativos da Apple.

- **Arquitetura MVVM:** a View apresenta a interface, a ViewModel organiza a lógica de apresentação e o Model representa os dados do app.
- **Persistência local:** uso de `@AppStorage` para manter dados entre sessões e refletir mudanças na interface.

### **[TechNews](https://github.com/raissareisls/TechNews.git)** · [Live Demo](https://raissareisls.github.io/TechNews/)

Leitor nativo em **SwiftUI** que reúne notícias de tecnologia em um feed.

- **Integração com APIs:** uso de `URLSession` para buscar os dados do feed em APIs REST externas e exibir as notícias no app.
- **Concorrência em Swift:** uso de `async/await` para aguardar as respostas de rede sem bloquear a interface durante o carregamento.

### **[Plataforma INSPIRE](https://github.com/raissareisls/Site-inspire.git)** · [Live Demo](https://raissareisls.github.io/Site-inspire/)

Desenvolvimento **full-stack** da plataforma oficial do projeto de extensão INSPIRE da UFC, com interface em **React, TypeScript e Tailwind CSS**.

- **Escopo do MVP:** priorização das funcionalidades essenciais para a primeira versão, com base nas necessidades das usuárias.
- **Evolução do produto:** organização das entregas em ciclos curtos com **metodologias ágeis**, para incorporar ajustes ao longo do desenvolvimento.
